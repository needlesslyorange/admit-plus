# Admit+

Dark Mode and 1-click school forum navigation for [Admit.org](https://med.admit.org).

## Features

- **5 Dark Themes**: Midnight, OLED, Slate, Mocha, and Indigo
- **1-Click School Navigation**: Jump directly from a school's Cycle Results to its active School Forum thread (`💬 School Forum ↗`) and back (`📊 Cycle Results ↗`)
- **High Contrast Mode**: Sharper card borders and thread outlines
- **Keyboard Shortcut**: `Alt + Shift + D` (or `Option + Shift + D` on macOS) to toggle Dark Mode instantly

## Installation

Download the latest release from the **[Releases](https://github.com/needlesslyorange/admit-plus/releases)** page.

### Chrome / Brave / Edge
1. Download and unzip `admit-plus-chrome.zip`.
2. Go to `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** (top left) and select the unzipped folder.

### Firefox
1. Download `admit-plus-firefox.zip`.
2. Go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on...** and select the downloaded `admit-plus-firefox.zip`.
